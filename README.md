# 東京五天四夜｜媽媽的旅行手帳（本機儲存版）

這是一個適合手機使用、純前端的旅行行程網站。已預先填入 **2027 年 1 月 7 日至 1 月 11 日** 的五天東京行程。

**不需要帳號、Firebase、資料庫或付費主機。** 可部署至 GitHub Pages，修改記錄留在使用者目前的瀏覽器本機儲存空間（localStorage）。

## 主要功能

- 5 天日期切換與時間軸行程，支援新增／編輯／刪除、調整時間與地點、修改提醒、標示是否已預約／完成。
- 每項地點直接開啟 Google Maps 搜尋。
- 旅行待辦清單、一般備忘錄。
- 每次按「儲存」都保留修改紀錄（最多 50 筆行程快照），可從修改紀錄還原舊版。
- 本機儲存：重新開啟**同一網站網址 + 同一個手機瀏覽器**會保留資料。
- **傳送完整行程檔**：在支援分享檔案的手機使用系統分享選單（選 LINE 傳給家人）；不支援的裝置會改為下載 JSON，需手動傳送。
- **分享文字版行程**：產生方便 LINE 閱讀的完整時間軸與修改摘要；若無分享功能，會複製文字或下載文字檔。
- **下載完整 JSON 備份**、**匯入 JSON 備份**：JSON 含行程、待辦、備忘錄、修改紀錄與歷史快照。
- 可列印全部五天行程，也可透過瀏覽器列印功能存成 PDF。
- 包含 Web App Manifest 和基本離線快取設定（首次連線開啟載入資源之後，部分功能可離線使用）。

## 部署到 GitHub Pages

1. 將 ZIP 解壓縮，取得 `index.html`、`app.js`、`data.js`、`style.css`、`sw.js`、`manifest.webmanifest` 和 `assets/` 資料夾。
2. 將**上述檔案和資料夾**一起放在 GitHub 儲存庫的同一層，提交（commit）並推送（push）到 `main`。
3. 在 GitHub 儲存庫開啟 **Settings → Pages**，於 **Build and deployment** 選 **Deploy from a branch**，Branch 選 `main` / `/(root)`，然後儲存。
4. GitHub Pages 網址通常是 `https://你的帳號.github.io/儲存庫名稱/`；請以 GitHub 顯示的實際網址為準。
5. 把 GitHub Pages 網址傳給媽媽。手機打開後就可以開始修改。

如果把檔案放在子資料夾，例如 `OfficeWeb/TokyoTrip/`，GitHub Pages 的可用網址會依儲存庫與部署目錄而定。**請確保公開網站的資料夾中有 `index.html`，而且其餘資源路徑相對正確。**

> 請使用 GitHub Pages 或本機 HTTP 開發伺服器開啟網站；直接在電腦雙擊 `index.html` 可能因瀏覽器限制無法載入 JavaScript 模組。

## 給媽媽的操作方式

1. 用手機開啟網站，底部選「行程」；選 Day 1～Day 5。
2. 按行程右下角「編輯行程」，修改後按「儲存更動」。
3. 要新增景點，按「＋ 新增行程」。待辦與備忘錄在「待辦」頁。
4. 改完後選底部「設定」，再選 **「傳送完整行程檔（推薦）」**。手機若跳出分享選單，選 LINE → 傳給家人。
5. 如果沒有跳出分享選單，會自動下載 JSON 檔；到手機的檔案／下載位置，將剛才的檔案透過 LINE 的「檔案」功能傳送。
6. 若只是想讓家人直接讀行程，按 **「分享文字版行程」**，可透過 LINE 傳送文字內容。

**重要：傳送「網站網址」不會帶上手機中修改過的資料。要給家人看修改後的內容，一定要傳送 JSON 檔或文字版。**

## 你收到媽媽的 JSON 後

- 你可以在自己的電腦用同一個網站按「設定 → 匯入行程備份」載入她修改過的版本，檢視內容。
- 也可以將 JSON 檔提供給協助修改網站的人員，將內容整理回 `data.js`，再重新部署 GitHub Pages。
- **只是在你的電腦匯入 JSON，並不會自動改變所有訪客看到的網站初始行程**；想讓新訪客看到新預設內容，需要更新網站程式中的 `data.js`。
- 已使用過網站的媽媽手機仍會優先讀自己的本機資料。若要套用新版本，請先替她備份，再使用「匯入備份」載入你提供的新 JSON；避免無意間覆蓋她已編輯的內容。

## 本機儲存注意事項

- 這個版本**不會跨手機／電腦同步**，而且不是伺服器備份。
- 無痕模式、清除網站資料、更換瀏覽器、解除安裝部分瀏覽器或系統的儲存空間清理，都可能造成資料遺失。iPhone Safari 也可能自動清理長期未使用的網站資料，因此建議定期下載 JSON 備份。
- 按行程編輯視窗中的「儲存更動」才會儲存該筆修改；直接關閉編輯畫面不會保留未送出的內容。
- 行程設定中保留 1/8 六本木櫸坂點燈及 1/11 KINTAN 午餐，依原來提供的安排呈現；請自行確認當年度活動及餐廳營業資訊。

## 開發時用本機伺服器預覽

```sh
cd tokyo-mama-trip
python -m http.server 8000
```

瀏覽 `http://localhost:8000`。停止服務不會刪掉瀏覽器內已儲存的資料。

## 專案結構

```text
index.html              網站版面
style.css               手機與電腦版型、列印樣式
app.js                  行程編輯、localStorage、修改紀錄、匯出匯入
 data.js                五天行程的預設初始內容
sw.js                   站點離線資源快取
manifest.webmanifest    加到手機主畫面的網站資訊
assets/                 插畫與網站圖示
```
